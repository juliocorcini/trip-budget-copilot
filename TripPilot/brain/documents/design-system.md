> Version: 1.0 | Date: 2026-06-08

## 1. Design Philosophy

TripPilot should feel like **a trusted instrument in your pocket** — warm enough to be a companion, precise enough to trust with real money. It's the intersection of a cockpit control panel and a Mediterranean evening: technically confident but humanly warm. The app smells like travel, not like a bank.

**Brand words:** Warm · Precise · Confident

**Anti-references:**
- Corporate banking apps (Revolut's coldness, N26's sterility)
- Generic finance-app blue/green
- AI purple/neon aesthetic
- Anxiety-inducing design (it should also ENCOURAGE spending when budget allows)
- Flat, template-like, "obviously AI-generated" interfaces

A second accent family, **distinct from the terracotta brand**, reserved for AI surfaces (Scan / AI entry / live split). Mnemonic: **terracotta = brand, indigo = AI**. Defined in `tokens.css` for both themes (light mode uses a deeper indigo so white text stays legible). Was previously hard-coded (`#6366F1`/`#818CF8`/`#8B5CF6`) across 9 files; now tokenized.

|---|---|---|---|---|
| Comfortable | #6B8F7110 | #6B8F71 | #6B8F7115 | Budget healthy, can spend freely |
| Attention | #D4A84310 | #D4A843 | #D4A84315 | Caution, trade-off exists |
| Avoid | #D9404010 | #D94040 | #D9404015 | Over budget, reserves at risk |

### Dark/Light Mode
- **Dark mode is PRIMARY** — optimized for bar usage at night
- Light mode is deferred to post-V1
- All neutrals are tinted warm toward terracotta hue (never pure gray)
- Text is warm cream (#EDE8E0), never pure white (#FFFFFF)
- Backgrounds are navy-charcoal tinted warm, never pure black (#000000)

### Color Rules
- Tint all neutrals toward the brand hue (terracotta warm)
- Follow 60-30-10: 60% surfaces, 30% secondary text/borders, 10% accent
- NEVER use pure black (#000000) — use --surface (#0F1419)
- NEVER use pure white (#FFFFFF) — use --on-surface (#EDE8E0)
- The ONLY sanctioned secondary accent is the indigo **AI family** (`--ai`/`--ai-2`/`--ai-strong`/`--ai-gradient`), reserved strictly for AI surfaces (Scan / AI entry / live split) — terracotta = brand, indigo = AI (M12/DEC-287). Do NOT introduce other accent hues (cyan-on-dark, neon) for general UI.
- NEVER use blue as the **brand/primary** accent — it's the generic finance-app color (the scoped indigo `--ai` family is the one exception, AI-surfaces only)
- Success/Warning/Error are functional ONLY — not decorative

## 3. Typography

### Font Stack
| Role | Family | Weight | Sizes | Source |
|---|---|---|---|---|
| Display/Headlines | Manrope | 700-800 | 1.5rem-2.375rem | Google Fonts |
| Body/Labels | Manrope | 400-600 | 0.75rem-1rem | Google Fonts |
| Monospace (money) | JetBrains Mono | 400-600 | 0.875rem-3.5rem | Google Fonts |

### Type Scale (fixed rem for app UI)
| Token | Size | Line Height | Weight | Usage |
|---|---|---|---|---|
| --text-display | 2.375rem (38px) | 1.05 | 800 | Primary monetary values |
| --text-heading | 1.375rem (22px) | 1.2 | 800 | Page titles |
| --text-subheading | 1rem (16px) | 1.3 | 700 | Section headings, card titles |
| --text-body | 0.875rem (14px) | 1.5 | 400-500 | Body text |
| --text-secondary | 0.75rem (12px) | 1.5 | 500-600 | Labels, metadata |
| --text-caption | 0.625rem (10px) | 1.4 | 600-700 | Captions, badges, nav labels |

### Typography Rules
- Use fixed rem scale (NOT fluid/clamp) — this is an app UI, not a marketing page
- Primary monetary values use Manrope 800 at --text-display size with tracking-tight
- ALL monetary values use `font-variant-numeric: tabular-nums` for alignment
- Cap line length at 65ch for body text
- Use tracking-tight (-0.02em) for display headings
- Use tracking-[0.15em] uppercase for section labels/badges
- Increase line-height by 0.05 for dark-mode text (lighter text weight perception)
- **All user-facing text in Portuguese** — code remains in English
- NEVER use Inter, Roboto, Arial, DM Sans, Space Grotesk (reflex fonts)

### Layout Templates

#### App Shell (authenticated screens)
- **No sidebar** — mobile-first PWA
- Bottom navigation: sticky, glass effect, 5 items + central FAB
- Content: scrollable, max-width 430px, centered (mx-auto)
- Page horizontal padding: 20px (mx-5)
- **Bottom padding: minimum 100px** to prevent content hidden behind fixed nav
- Status bar at top: phase name (real name, not "Fase Dashboard") + action button

#### Budget Breakdown Display Rule (CRITICAL)
The dashboard MUST show budget in this hierarchy:
1. **Hero number**: "Livre para usar até [data final da fase]" — the ONLY number that matters
2. **Secondary breakdown** (below, smaller):
   - Saldo restante do fundo: €X
   - Reservado para fases futuras: €X
   - Reserva protegida: €X
   - = Livre para usar: €X (hero)
- NEVER show "Saldo operacional" as the primary number without explaining what's truly free
- The user must never confuse total fund balance with spendable money

#### Outing Mode (immersive, DEDICATED SCREEN)
- Full-screen, deeper background (--surface-deep)
- **No bottom navigation** — replaced by quick-add buttons at the bottom
- **Quick-add buttons MUST be visible without scrolling** — this is non-negotiable
- Central value (gasto pessoal) dominates viewport at 64px
- Layout from top to bottom: header → value → "ainda pode gastar" → drink segments → gauge → spacer → next drink impact → quick-add buttons
- Uses flex column with flex-1 spacer to push buttons to bottom
- Back button to return to dashboard
- On dashboard, shows compact card with "Abrir sessão" button

#### Welcome/Onboarding
- Centered layout, no bottom navigation
- Full-height with vertical centering
- Step indicator at top
- Actions at bottom

## 7. Motion & Animation

### Easing Curves
```css
--ease-out: cubic-bezier(0.23, 1, 0.32, 1);
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
```

### Duration Scale
| Element | Duration | Easing |
|---|---|---|
| Button feedback | 100ms | ease-out |
| Quick-add press | 100ms | ease-out |
| Toast enter | 200ms | ease-out |
| Toast exit | 150ms | ease-out |
| Bottom sheet | 250ms | ease-out |
| Modal | 250ms | ease-out |
| Drink segment change | 200ms | ease-out |
| Gauge segment fill | 300ms | ease-out |
| Page transition | 200ms | ease-in-out |

### Animation Rules
- NEVER animate from scale(0) — start from scale(0.95) + opacity(0)
- NEVER use ease-in for UI — it feels sluggish
- NEVER animate width/height/padding/margin — only transform and opacity
- UI animations MUST stay under 300ms
- Buttons: scale(0.97) on :active, 100ms
- Outing quick-add: brief scale feedback + segment update
- Drink segment pulse: only on the LAST segment before limit (1.8s infinite)
- Stagger lists: 40ms between items
- Exit faster than enter (enter 250ms, exit 150ms)
- Respect prefers-reduced-motion: keep opacity transitions, remove transforms

## 8. Anti-Patterns (BANNED)

### Visual
- Side-stripe borders (border-left > 1px with accent color)
- Gradient text (background-clip: text)
- Pure black (#000000) backgrounds or text
- Pure white (#FFFFFF) backgrounds
- Cards inside cards (flatten hierarchy)
- Same-sized card grids repeated endlessly
- Hero metric layout (big number, small label, gradient accent)
- Blue as primary/accent color
- Purple/neon AI aesthetic
- Emojis in UI
- Generic placeholder names ("John Doe", "€100.00")
- Unsplash image links

### Typography
- Inter, Roboto, Arial, DM Sans, Space Grotesk as fonts
- Centered hero sections
- Text without tabular-nums for monetary values
- Body text wider than 65ch

### Animation
- transition: all (specify exact properties)
- ease-in on UI elements
- Duration > 300ms on interactive elements
- No :active state on buttons
- Keyframes on rapidly-triggered elements
- scale(0) as animation start

### Structure
- Sidebar navigation (mobile-first PWA)
- Dropdown menus instead of bottom sheets on mobile
- Modal dialogs for quick actions (use bottom sheet)
- Full-page forms when bottom sheet suffices
